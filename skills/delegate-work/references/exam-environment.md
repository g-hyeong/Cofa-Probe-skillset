# 시험 환경에서의 모델·도구 사용

Cofa Probe에서 위임하기 전에 해당 시험 안내와 현재 작업 환경을 확인한다. 시험에서 허용한 범위와 현재 도구에서 실제로 지원하는 기능이 겹치는 범위에서 위임한다.

## 작업별 선택

짧거나 결합도가 높은 일은 부모가 직접 처리한다. 위임할 때는 아래 기준을 참고해 작업에 맞는 모델과 추론 수준을 고른다.

| 작업 조건 | 모델·추론 선택 기준 |
| --- | --- |
| 입력과 판단 기준이 명확한 자료 추출, 반복 변환, 체크리스트 점검 | 좁은 작업 범위를 처리할 수 있는 설정 |
| 계약이 확정된 기능·테스트 구현, 범위가 명확한 결함 수정 | 필요한 코드 맥락과 검증을 처리할 수 있는 설정 |
| 상충하는 근거 비교, 구조 설계, 어려운 원인 분석, 영향이 큰 독립 검토 | 필요한 판단과 근거 비교를 처리할 수 있는 설정 |

실패 비용과 다른 작업에 미치는 영향을 함께 보고 결정한다. 중요한 제품 결정과 사용자 조율은 부모가 맡는다.

## 호출과 기록

1. 현재 위임 도구의 모델 목록·선택 필드·지원 추론 값·맥락 상속 제약을 확인한다. 실제로 확인한 모델 ID를 사용하고, 기본·상속 모델에 의존할 때는 그 모델을 사용할 수 있는지 확인한다.
2. 모델과 추론 수준은 도구가 지원하는 필드에서 각각 지정한다. 필요한 입력과 맥락만 전달한다. 허용된 위임 기능을 확인할 수 없으면 제공된 작업 환경에서 부모가 직접 처리한다.
3. 위임한 작업과 선택 근거를 기록한다. 실행 응답에서 실제 모델을 확인할 수 있으면 요청값과 대조한다.

## 실패와 재배정

결과가 부족하면 입력·범위·누락 맥락부터 고친다. 판단 난도가 원인이면 허용되고 지원되는 범위에서 모델이나 추론 수준을 조정한다. 필요한 설정을 사용할 수 없으면 작업을 나누거나 부모가 직접 처리한다. 재배정에는 확정 결과와 남은 일, 필요한 실패 원인만 전달한다.

동시 작업 수는 도구 한도, 작업 독립성, 수정 충돌을 기준으로 정한다. 자료 접근, 외부 전송, 제출은 해당 시험 안내의 범위를 따른다.
